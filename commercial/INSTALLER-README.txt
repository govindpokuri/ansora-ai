Ansora AI - Windows installer

Run AnsoraAI-Setup.exe, follow the wizard, then open Ansora AI from the Start
menu. The app installs for your current Windows user without administrator
access. Close the application before installing an update.

On first launch, sign in with the email used on https://example.com.
You can also select Options > Sign in. Once signed in, your email appears
in the Options menu; select it to manage your account or sign out.
Add a resume after sign-in, or choose Skip for this call. AI model and endpoint settings are managed by the server.
AI answers and resume analysis require purchased tokens. The Azure key stays
on the server and is never included in this installer.

Select the same playback device as your call, then click Start listening.
Only caller/system playback is transcribed; your microphone is not included.
Upload and review your resume to personalise suggestions and coding languages.

For a written question or coding problem, open Text & code and paste with
Ctrl+V. Include examples, constraints and any existing code. Keep Include a
coding solution checked for code, or uncheck it for a normal text answer.
Click Get answer or press Ctrl+Enter. Click Cancel answer to stop a request.
Caller transcription continues; automatic answers pause while this tab is
open. Return to Caller to resume automatic answers for new caller questions.
Select answer text and press Ctrl+C to copy. Pasted questions, answers and
reported token usage are included in the call export and normal billing.

Use Ctrl+Alt+Q to close, Ctrl+Alt+H to hide/restore. No tray icon is added.
Open Options to access account, resume, settings, saved calls and export.
The aligned menu floats above the content and does not resize the answer.
Use the Background slider to adjust the window background from solid to
transparent. Below 70%, brighter text and dark shadows improve contrast.
The preference is saved. Enable Pass clicks to desktop to operate apps behind
the window; Ctrl+Alt+T restores clicking and scrolling in Ansora.
Updates are checked on startup and every 15 minutes while the app runs.
A yellow Update available badge appears beside Options when a newer version
is published. Finish your call, then select the badge to download, verify
and install the update. Calls are saved automatically before setup starts.
Account details, settings and your saved resume are preserved across updates.
Calls save automatically to Documents/Ansora AI/Calls while listening, on
stop and on exit. Options > Saved calls opens these HTML and JSON files.
Options > Export a copy can also save a snapshot during a call. Reports can
contain resume context and are not encrypted; delete them when not needed.
Use Keep this on screen to hold the current answer while reading.

Uninstall using Windows Settings > Apps > Installed apps > Ansora AI.
Your locally saved resume profile, settings and exported reports are preserved.

Requires Windows 11 x64. .NET and the English speech model are included.
The Microsoft Visual C++ runtime may also be required on a fresh computer;
download it from Microsoft's official website if local speech cannot load.
This preview is unsigned; production code signing is still required for a
verified publisher identity. The website/backend must be deployed before
public account access and AI use are available.

Use AI suggestions in permitted conversations and review them for accuracy.
Screen-capture exclusion depends on the sharing software and is not guaranteed.
