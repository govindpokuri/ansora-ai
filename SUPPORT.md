# Support / donate

Donations are optional. No payment destination is configured yet. The maintainer
can add a verified GitHub Sponsors, Ko-fi, Buy Me a Coffee or payment-link URL
here and to `.github/FUNDING.yml`. Never use a placeholder payment account or
the token-purchase endpoint as a donation destination.

Until then: star or share the repository, improve documentation, report useful
bugs, review a pull request, or contribute a fix. Donations do not buy hosted
token credits, extra features, guaranteed support or ownership.
