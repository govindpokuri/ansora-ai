# Contributing

Fork the repository, create a focused branch and describe the problem and
resulting behavior in your pull request. Include relevant validation; build
and test commands are in README.md. Match the existing C#/PHP style.

Use mock providers and fictional profiles. Never attach real calls, resumes,
credentials or customer records. Billing/authentication changes need tests for
failure cases. Retain third-party licenses and avoid unrelated formatting changes.

Contributions are submitted under MIT. Confirm you have the right to contribute
the material. Be respectful and keep discussion focused on the work.
For vulnerabilities, follow SECURITY.md instead of filing a public issue.
